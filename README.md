## 🚀 Projetos em Destaque

### 🍎 [Projeto Maçãs](https://github.com/GustavoSchwabeRazera/Projeto-Macas)

Projeto de **Machine Learning** desenvolvido em Python para previsão da qualidade de maçãs.

O sistema utiliza **5 modelos de classificação** simultaneamente:

* Naive Bayes
* KNN
* Decision Tree
* Random Forest
* SVC

Também possui uma aplicação web desenvolvida com **Streamlit** e disponível online.

🔗 [Testar aplicação](https://projeto-ma-s-abfhet9md4ebhspjsx7fkv.streamlit.app/)

**Tecnologias:** `Python` `Scikit-Learn` `Streamlit` `Pandas` `NumPy`

---

### 🖐️ [DetectorMao](https://github.com/GustavoSchwabeRazera/DetectorMao)

Projeto de **visão computacional** que permite controlar funções do computador utilizando apenas gestos feitos com a mão através da webcam.

É possível controlar:

* 🔊 Volume
* 🔇 Mute
* ▶️ Play/Pause
* ⏹️ Desligamento do computador

O projeto utiliza o **MediaPipe** para detectar os 21 pontos da mão e o **OpenCV** para captura da webcam.

**Tecnologias:** `Python` `MediaPipe` `OpenCV`

---

### 🤖 [Analisador de Avaliações](https://github.com/GustavoSchwabeRazera/AnalizadorDeAvaliacoes)

Aplicação em Python que utiliza **IA local** através do Ollama para analisar avaliações de produtos.

O sistema classifica cada avaliação como:

🟢 Positiva
🟡 Neutra
🔴 Negativa

Além disso, calcula uma média de sentimento e uma nota de qualidade percebida.

O projeto utiliza o modelo **Llama 3.2 (3B)** executado localmente.

**Tecnologias:** `Python` `Ollama` `Llama 3.2` `IA`
